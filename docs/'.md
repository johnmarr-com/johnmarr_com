# Trivia — Claude Max Prompts for Remaining 6 Verticals

For verticals where no clean public ranked dataset exists. Each prompt produces a JSON array that gets pasted into the **Or paste JSON directly** textarea on the AI Agents panel.

## Workflow

1. Pick a prompt below, paste into [claude.ai](https://claude.ai) (Claude Max).
2. Wait for the JSON output.
3. Copy the JSON array (everything from `[` to `]`).
4. Inventing.Studio → **AI Agents** → pick matching **Game** + **List**.
5. Paste the JSON into the **Or paste JSON directly** textarea (overrides the Source URL automatically).
6. Hit **Run Agent**.
7. Verify in the **Content Browser** below.

## Canonical output shape (all six prompts use this)

```json
[
  {
    "rank": 1,
    "name": "...",
    "creator": "...",
    "year": 1969,
    "genre": "...",
    "citationUrl": "https://en.wikipedia.org/wiki/..."
  }
]
```

`creator`, `year`, `genre`, `citationUrl` are optional — emit only when meaningful for the category.

If Claude Max truncates an array mid-output (hits token limit), ask it to *"continue from rank N, return ONLY the additional items as a JSON array"*, then concatenate before pasting (or accept the truncated count).

## 1. Plated — Top Dishes

> Game: **Plated** · List: **Top 500 Dishes**

```
Generate a ranked list of the most globally famous and culturally significant dishes for a trivia game. Goal is dishes that a wide audience would recognize, not regional specialties known only locally.

Target: 200-300 items. Hard floor: 150. Stop when you'd be reaching for obscure entries.

Rank by global recognition + cultural significance combined. Pizza, sushi, hamburger near the top; obscure regional dishes near the bottom or excluded.

Return ONLY a JSON array. No prose. Each item:
{
  "rank": 1,
  "name": "Pizza Margherita",
  "creator": "",  // dishes rarely have an attributable creator — usually empty
  "year": null,   // omit if unknown
  "genre": "Italian",  // cuisine of origin
  "citationUrl": "https://en.wikipedia.org/wiki/Pizza_Margherita"
}

Rules:
- Use exact Wikipedia URL slugs you know exist; skip citationUrl if uncertain.
- "genre" = cuisine (Italian, Japanese, Mexican, French, Indian, Chinese, Thai, etc.).
- Skip beverage-only entries (no plain coffee, tea, beer — but cocktails like Old Fashioned are fine).
- Output ONLY the JSON array. Begin with [, end with ].
```

## 2. Extra Extra — Top Historical Events

> Game: **Extra Extra** · List: **Top 500 Historical Events**

```
Generate a ranked list of the most consequential events in world history for a trivia game.

Target: 200-300 items. Hard floor: 150. Rank by historical impact + global awareness combined.

Include wars, revolutions, falls of empires, pandemics, scientific revolutions, religious schisms, treaties, assassinations of major figures, civil rights milestones, technological turning points (when they're event-shaped, not invention-shaped — e.g. moon landing yes, "invention of internet" no).

Return ONLY a JSON array. Each item:
{
  "rank": 1,
  "name": "World War II",
  "creator": "",
  "year": 1939,    // start year for multi-year events; single year for moments
  "genre": "war",  // war | revolution | political | scientific | religious | natural | cultural | civil_rights | economic
  "citationUrl": "https://en.wikipedia.org/wiki/World_War_II"
}

Rules:
- For multi-year events, use the start year and reference the period in the name if needed (e.g. "Black Death" 1346, "Cold War" 1947).
- Skip events that are really inventions or discoveries — those belong in a different category.
- Output ONLY the JSON array. Begin with [, end with ].
```

## 3. Geek Freak — Top Scientific Discoveries / Inventions

> Game: **Geek Freak** · List: **Top 500 Scientific Discoveries**

```
Generate a ranked list of the most important scientific discoveries and inventions for a trivia game.

Target: 250-400 items. Hard floor: 200. Rank by impact on humanity + scientific significance combined.

Include both pure-science discoveries (gravity, evolution, DNA structure, general relativity) and engineering inventions (printing press, steam engine, transistor, vaccines, antibiotics). Mix is fine.

Return ONLY a JSON array. Each item:
{
  "rank": 1,
  "name": "Theory of Evolution by Natural Selection",
  "creator": "Charles Darwin",  // primary discoverer/inventor; "" if unknown
  "year": 1859,
  "genre": "biology",  // physics | chemistry | biology | medicine | astronomy | mathematics | engineering | computing | materials
  "citationUrl": "https://en.wikipedia.org/wiki/On_the_Origin_of_Species"
}

Rules:
- For year, use first publication / public demonstration / patent year.
- For ancient discoveries with no known author, use "" creator and best-estimate year.
- Output ONLY the JSON array. Begin with [, end with ].
```

## 4. Ctrl Alt Defeat — Top Tech / Computing Milestones

> Game: **Ctrl Alt Defeat** · List: **Top 500 Tech Milestones**

```
Generate a ranked list of the most important tech and computing milestones for a trivia game. Focus is products, services, and events from ~1940 to present — NOT scientific discoveries (those belong elsewhere).

Target: 200-300 items. Hard floor: 150. Rank by impact on tech industry + cultural significance.

Include hardware (ENIAC, IBM 360, Apple II, Macintosh, iPhone), software (DOS, Windows 95, Linux, Photoshop), services (ARPANET, Mosaic, Google Search, Facebook, Wikipedia, ChatGPT), companies-as-events (Apple founding, Microsoft IPO, Google IPO), and pivotal industry moments (dot-com crash, iPhone announcement).

Return ONLY a JSON array. Each item:
{
  "rank": 1,
  "name": "iPhone (original)",
  "creator": "Apple",  // company or person responsible
  "year": 2007,
  "genre": "hardware",  // hardware | software | service | company_event | network | language
  "citationUrl": "https://en.wikipedia.org/wiki/IPhone_(1st_generation)"
}

Rules:
- Concrete dated events/products beat abstract concepts. ARPANET (1969) yes; "the internet" no.
- For products with multiple versions, list significant releases separately (Windows 95, Windows XP, Windows 7) only if each was independently culturally significant.
- Output ONLY the JSON array. Begin with [, end with ].
```

## 5. Pop Wow — Top Pop Culture Moments

> Game: **Pop Wow** · List: **Top 500 Pop Culture Moments**

```
Generate a ranked list of defining pop culture moments — singular events that became cultural touchstones — for a trivia game.

Target: 200-300 items. Hard floor: 150. Rank by cultural impact + lasting recognizability.

Include: TV/film moments (Beatles on Ed Sullivan 1964, M*A*S*H finale, Game of Thrones final, Seinfeld finale), live events (Live Aid 1985, Woodstock 1969, Super Bowl halftime moments), scandals/incidents (Janet Jackson Super Bowl 2004, OJ Bronco chase 1994, Britney head shave 2007), award show moments (Will Smith slap 2022, Kanye-Taylor VMAs 2009), viral internet moments (dress color 2015, Ice Bucket Challenge 2014).

NOT included: products (those belong in tech/games/etc), people (those belong in celebrities), generic "decades" (the 80s).

Return ONLY a JSON array. Each item:
{
  "rank": 1,
  "name": "Beatles on Ed Sullivan",
  "creator": "",  // usually "" — moments aren't created by one entity
  "year": 1964,
  "genre": "television",  // television | live_event | scandal | award_show | viral_internet | sports_moment | music_event
  "citationUrl": "https://en.wikipedia.org/wiki/The_Beatles%27_first_visit_to_the_United_States"
}

Rules:
- Each entry is a SPECIFIC dated event, not a trend.
- Output ONLY the JSON array. Begin with [, end with ].
```

## 6. Where In The — Top Landmarks

> Game: **Where In The** · List: **Top 500 Places**

```
Generate a ranked list of the most globally famous landmarks and places for a trivia game.

Target: 300-500 items. Hard floor: 250. Rank by global recognition + cultural/historical significance.

Include: man-made wonders (Eiffel Tower, Great Wall, Pyramids, Taj Mahal, Statue of Liberty), natural wonders (Grand Canyon, Mount Everest, Niagara Falls, Great Barrier Reef), iconic cities-as-landmarks for trivia (Vatican City, Times Square — only when distinctly recognizable), UNESCO sites with global fame, religious sites (Mecca, Western Wall).

Skip: countries themselves (Japan, France) — too broad; airports, hotels, sports stadiums (unless extraordinarily iconic like Yankee Stadium, Maracanã).

Return ONLY a JSON array. Each item:
{
  "rank": 1,
  "name": "Eiffel Tower",
  "creator": "Gustave Eiffel",  // architect/builder if known and famous; otherwise ""
  "year": 1889,  // year built/established/discovered
  "genre": "monument",  // monument | natural_wonder | religious_site | ancient_ruin | bridge | tower | castle | square | district
  "citationUrl": "https://en.wikipedia.org/wiki/Eiffel_Tower"
}

Rules:
- Each landmark must be a SPECIFIC PLACE, not a region.
- For natural wonders, "year" can be omitted.
- Output ONLY the JSON array. Begin with [, end with ].
```
